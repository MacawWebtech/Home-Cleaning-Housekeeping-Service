# CLEANORA – Home Cleaning & Housekeeping Service HTML Template

A modern, production-quality, responsive HTML5 template for professional cleaning and housekeeping businesses, featuring an extensive public marketing website, a complete customer management portal, and an operations admin dashboard.

---

## Highlights & Features

- **Strict Three-Colour Brand Identity:** Black (`#111111`), White (`#FFFFFF`), and Electric Lime (`#C6FF00`).
- **Typography:** Exactly two Google Fonts – `Manrope` (Headings) & `Inter` (Body).
- **Full-Width Edge-to-Edge Architecture:** Mandatory 30px side padding on Desktop & Tablet, 18px on Mobile.
- **Dark Mode & Light Mode:** System preference detection + persistent local toggle.
- **Full RTL Support:** Native Right-To-Left layout mirroring (`dir="rtl"`) for Hebrew and Arabic.
- **Interactive Multi-Step Booking Engine:** 5-step calculator with live pricing in INR (`₹`), bedroom steppers, add-on checkboxes, interactive calendar date & time slots.
- **Customer Portal (11 Pages):** Manage appointments, reschedule slots, recurring plans, printable invoices, and saved addresses.
- **Admin Dashboard (13 Pages):** Revenue charts, dispatch schedules, cleaner assignment dropdowns, service catalog manager, and review moderation.
- **Total Pages:** 43 fully coded HTML files with zero broken links.
- **Accessibility:** WCAG 2.1 AA compliant color contrast ratios and minimum 44px touch targets.
- **Documentation:** Complete installation, customization, page structure, and backend integration guides.

---

## Quick Start
1. Open `index.html` in any web browser.
2. Or run a local HTTP server: `python -m http.server 8000` and open `http://localhost:8000`.
